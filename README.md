# webproduksjon.no

Statisk, responsiv nettside bygget direkte i dette GitHub-repositoriet. Designet er rekonstruert fra brukerens 1152 × 2048-referansebilde; se [referanseanalysen](reference-analysis.md).

## Lokal visning

```bash
python3 -m http.server 8000
```

Åpne `http://localhost:8000/`. GitHub Pages serverer filene direkte fra `main`/rotmappen. Det finnes ingen byggetrinn eller Manus-hosting.

Kontaktskjemaet åpner besøkendes e-postprogram med et utkast adressert til `webproduksjon@gmail.com`. Det sender **ikke** meldingen automatisk. Dette er oppgitt under skjemaet; e-postprogram må være konfigurert hos besøkende.

## Bilder og innhold

- `renats-portrait.jpg` er levert av nettstedets eier.
- `abc-house.webp` er fra [ABC Bygg AS' publiserte nettside](https://abcbyggas.no/) og vises kun som ekte prosjekt.
- De øvrige dekor- og konseptbildene er hentet via bildeoppslag fra [Unsplash](https://unsplash.com/license) og brukes ikke som bevis for gjennomførte kundeoppdrag.
- Elektriker og snekker/tømrer er tydelig merket som **konseptdemoer**, ikke kunder.

Startprisene er oppgitt uten merverdiavgift. Foretaket er ikke registrert i Merverdiavgiftsregisteret. Endelig pris og omfang avklares før oppstart.
